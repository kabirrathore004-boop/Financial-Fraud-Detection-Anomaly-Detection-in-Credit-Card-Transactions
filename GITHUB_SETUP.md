# GitHub setup (copy-paste)

**Repository name:** financial-fraud-detection

**About (description):**
End-to-end data analytics project on 389K credit card transactions using Excel, MySQL, Python and Tableau to uncover fraud patterns by state, city, category, amount and time of day.

**Topics:**
fraud-detection, data-analytics, sql, mysql, python, eda, tableau, excel, data-visualization, anomaly-detection

**Resume / LinkedIn description:**
Analyzed 389,197 credit card transactions (0.58% fraud) using MySQL, Python and Tableau. Found that fraud transactions average $518 vs $68 for legitimate ones, and that about 86% of fraud occurs between 10 PM and 3 AM. Built an interactive Tableau dashboard with fraud maps and time trends, and recommended category-, region- and time-based controls.
